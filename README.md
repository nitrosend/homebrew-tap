# Nitrosend Homebrew tap

Homebrew formulae for Nitrosend's open-source tools.

```sh
brew install nitrosend/tap/nitromta
```

- [`nitromta`](https://nitromta.com): the open-source Amazon SES replacement,
  built in Rust. Each formula is published by its project's release workflow,
  pointing at the release's archives by URL and SHA-256.
